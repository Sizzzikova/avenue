# Бот акций «Авеню» → Telegram

Раз в сутки в 10:00 МСК собирает автомобили со спеццены с трёх поддоменов
`avenuerent.ru` и, **если состав машин или цены изменились**, публикует дайджест
с фото в Telegram-канал. Если на сайте ничего не поменялось — молчит.

Города: Новосибирск, Иркутск, Горно-Алтайск.

## Как это работает

Раздел `/aktcii/` на сайте — это не статьи об акциях, а список машин со скидкой
(`<h1>Специальные цены на аренду авто</h1>`). Сбор идёт в два шага, потому что
**цены в HTML отсутствуют**: их подставляет JavaScript уже в браузере.

1. `GET /aktcii/` — из карточек `.default_car_data` берём id машины, название,
   ссылку, фото, базовую цену и срок действия скидки.
2. `POST /ajax/calc_catalog.php` с `id` машины — тот же запрос, что делает сайт;
   отдаёт `dayPrice`, `oldDayPrice` и `discountTag` (процент скидки).

Так мы обходимся без headless-браузера: 3 GET и ~7 POST в сутки.

Состояние прошлого запуска лежит в `state/snapshot.json`. Публикация происходит,
только если отпечаток нового слепка отличается от сохранённого. Смена фотографии
на сайте на отпечаток не влияет — иначе она вызывала бы лишний пост.

## Запуск

```bash
pip install -r requirements.txt

# посмотреть, что получится, ничего не отправляя
PYTHONPATH=src python -m avenue_bot.main --mode dry-run

# записать текущее состояние, не публикуя (нужно один раз перед включением)
PYTHONPATH=src python -m avenue_bot.main --mode seed

# боевой запуск
PYTHONPATH=src python -m avenue_bot.main --mode run

python -m pytest
```

Режим по умолчанию — `dry-run`, чтобы случайный запуск ничего не отправил.

## Секреты

Задаются в GitHub: Settings → Secrets and variables → Actions. В коде и в
репозитории их нет и быть не должно — репозиторий публичный.

| Секрет | Обязателен | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | да | канал для постов, например `@avenue_channel` |
| `TELEGRAM_ADMIN_CHAT_ID` | нет | служебный чат для алертов о поломке |

Без `TELEGRAM_ADMIN_CHAT_ID` бот работает, но о сбоях сообщает только красным
прогоном в Actions. Задайте его — тогда о поломке придёт сообщение в Telegram.

## Что делать, если бот перестал находить машины

Скорее всего, на сайте изменилась вёрстка. Код при этом трогать не нужно —
правится секция `selectors` в `config.yml`:

```yaml
selectors:
  card: .default_car_data       # карточка машины целиком
  item: .cars__item             # блок с атрибутом static-price
  car_id: .colors a[data-car]   # id для запроса цены
  link: a[href^="/autopark/cars/"]
  image: img[data-src]
```

Как подобрать новые: откройте `https://avenuerent.ru/aktcii/`, нажмите Ctrl+U,
найдите блок вокруг названия машины и подставьте актуальные классы. Проверить
можно локально, положив свежий исходник в `tests/fixtures/aktcii-nsk.html`
и запустив `python -m pytest`.

Бот специально падает с ошибкой, если карточек найдено ноль: пустой результат
почти всегда означает сломанные селекторы, а не отсутствие скидок, и молча
принимать его нельзя — иначе канал тихо замолчит на недели.

## Как временно выключить

- Разово: Actions → Avenue · дайджест акций → «···» → Disable workflow.
- Только Telegram, оставив сбор данных: `telegram.enabled: false` в `config.yml`.

## Подключить MAX

Отложено: с августа 2025 боты в MAX выдаются только российским юрлицам.
Когда токен появится — см. инструкцию в `src/avenue_bot/senders/max.py`.
Остальной код к этому готов, отправители независимы.

## Структура

```
config.yml               города, селекторы, лимиты, тексты
src/avenue_bot/
  models.py              Car
  config.py              config.yml + секреты из окружения
  fetch.py               HTTP: ретраи, таймауты, браузерный User-Agent
  parse.py               карточки из HTML + добор цен через AJAX
  state.py               слепок состояния и правило «публиковать или нет»
  render.py              сборка дайджеста под лимиты Telegram
  senders/telegram.py    альбом, запасной путь для .webp
  senders/max.py         заглушка
  alerts.py              уведомления о сбоях
  main.py                CLI
tests/                   фикстуры — реальные страницы сайта от 13.08.2026
state/snapshot.json      состояние, коммитится ботом
```
